两大核心能力

先把最重要的事做对，其余的才叫锦上添花。

📖

AI 读到的，就是你看到的

把链接丢给网页版 AI？它在服务端 fetch 到的是没跑过 JavaScript 的空壳—— 动态加载的信息流、要点开的折叠内容、登录后才可见的页面，统统抓不到。

LLM Sidebar 读的是你浏览器里渲染完成的页面：你看到什么，它就读到什么。 正文、动态内容、表格数据都能答，来源与工具轨迹全程可查。

动态页面读得到登录后内容读得到轨迹透明
🗂

全程在浏览器里，零切换

不用复制链接到新窗口，不用截图贴进聊天框，不用在应用之间来回跳。 侧边栏常驻在当前页旁边，眼前这页就是上下文，边看边问。

要参考更多页面？顶部「上下文」勾选多个标签页，一句话对比—— 「对比这两页的价格方案」，直接出对比表格，来源逐页可查。

侧边栏常驻当前页即上下文多标签对比

更多顺手的小功能

不喧宾夺主，需要时都在。

🖼

看得见图片

搭配 glm-4v 等视觉模型，截取页面或抓取图片分析图表；截图直接显示在对话轨迹里，AI 看到了什么一目了然。

🔍

完整 HTML 模式

开关打开即读渲染后的完整 DOM，也能只取某个选择器匹配的局部——「这个组件的 class 结构是什么」终于能答了。

⚙️

对话改配置

「换到 glm-4v」「单页上限调到 20 万」，说完即生效并自动保存；密钥与端点只能手动改。

🔌

任意模型端点

GLM、官方 Claude、OpenRouter 等 Anthropic 协议端点；填好密钥一键拉取模型列表点选。

🧩

MCP 扩展

配置远程 MCP server（streamable HTTP），联网搜索、笔记库、数据库工具随接随用。

📤

配置随身带

配置导出 JSON，换电脑导入即恢复；密钥与全部配置只存本机。

你的数据留在你手里

没有账号、没有云端、没有统计上报。

🔐

数据只在本机

API Key 与全部配置只存在浏览器本机（chrome.storage.local），导出的配置文件也只落在本机。

👁

默认最小可见

AI 默认只能读取你在「上下文」里勾选的标签页；「允许读取所有标签页」是设置里的手动开关，且无法通过对话自行打开。

📡

不多走一个字节

除你配置的模型端点与 MCP server 外，扩展不向任何地方发送数据，也没有任何埋点与上报。

三步开问

从安装到第一次提问，不超过五分钟。

1

安装扩展

  1. 从 Releases 下载 zip 并解压
  2. 打开 chrome://extensions，开启「开发者模式」
  3. 「加载已解压的扩展程序」→ 选择解压目录

也可克隆源码后 npm install && npm run build，加载 dist/

2

配置模型

  1. 侧边栏右上角 ⚙ 进入设置
  2. 填 API Base URL 与 API Key
    （GLM 填 https://open.bigmodel.cn/api/anthropic）
  3. 点「获取列表」选模型 → 保存

支持任意 Anthropic 协议兼容端点：官方 Claude、OpenRouter 等

3

打开网页开问

  1. 打开任意网页，在侧边栏输入问题
  2. Enter 发送，Shift+Enter 换行
  3. 顶部「上下文」勾选想让 AI 参考的标签页

页面内容更新后，说「重新读一下当前页」即可刷新
